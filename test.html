本地使用与跨域说明

可直接用浏览器打开此文件。若 API 与页面不同源（包括 file:// 打开），后端需要允许跨域来源、请求方法和 Content-Type 请求头，并处理 OPTIONS 预检。

当前项目可通过 http://localhost:8080/test.html 同源访问此页面，无需跨域配置。若直接打开文件，详情和 PATCH 接口仍需要补充 CORS。页面无法绕过浏览器的跨域限制。

Response Headers 仅显示浏览器允许读取的响应头；跨域时，额外响应头需要后端通过 Access-Control-Expose-Headers 暴露。
